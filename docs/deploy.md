# Как перенести бота на сервер (VPS)

Сервер работает круглосуточно, поэтому бот будет присылать напоминания, даже когда ваш компьютер выключен.
Займёт около часа. Все команды ниже можно копировать целиком.

> ⚠️ Один токен = один запущенный бот. Перед запуском на сервере **остановите бота на компьютере** (Ctrl+C в терминале). Если они будут работать одновременно, в логах появится `TelegramConflictError`.

## Шаг 1. Арендуйте сервер

Подойдёт любой VPS с такими параметрами:

- **ОС:** Ubuntu 24.04
- **Процессор и память:** 1 ядро, 1 ГБ RAM, 10 ГБ диска (самый дешёвый тариф)
- **Расположение:** лучше за пределами России (Нидерланды, Финляндия, Германия), потому что доступ к серверам Telegram оттуда стабильнее

Примеры провайдеров: Timeweb Cloud, Selectel, Aeza, Hetzner. Цена примерно 200–500 ₽ в месяц.

После создания сервера провайдер покажет (или пришлёт на почту) **IP-адрес** и **пароль root**.

## Шаг 2. Подключитесь к серверу

Откройте терминал на компьютере (Windows: PowerShell, macOS: «Терминал») и выполните, подставив свой IP:

```
ssh root@123.45.67.89
```

На вопрос `Are you sure you want to continue connecting` напишите `yes`. Затем введите пароль и нажмите Enter. Символы пароля при вводе не отображаются, так и должно быть.

Если в начале строки появилось `root@...:~#`, вы на сервере. Все следующие команды выполняются **там**.

## Шаг 3. Установите Docker

```
curl -fsSL https://get.docker.com | sh
```

Проверка: команда `docker compose version` должна напечатать номер версии.

## Шаг 4. Скачайте бота

```
git clone -b main https://github.com/darinavladi/tg_bot_claude.git
cd tg_bot_claude
```

## Шаг 5. Впишите токен

```
cp .env.example .env
nano .env
```

Откроется редактор. Замените `123456:ABC-your-token` на свой токен от @BotFather. Строку `DATABASE_URL` трогать не нужно. Сохраните: **Ctrl+O**, Enter, затем выйдите: **Ctrl+X**.

## Шаг 6 (по желанию). Перенесите свои события с компьютера

Если вы уже пользовались ботом на компьютере и хотите сохранить события, перенесите файл базы.
Сначала на **сервере** создайте папку:

```
mkdir -p /root/tg_bot_claude/data
```

Потом на **компьютере** (в новом окне терминала, в папке бота) выполните:

```
scp planner.db root@123.45.67.89:/root/tg_bot_claude/data/
```

## Шаг 7. Запустите

На сервере, в папке `tg_bot_claude`:

```
docker compose up -d --build
```

Первый запуск займёт пару минут. Проверьте логи:

```
docker compose logs -f
```

Должна появиться строка `Start polling`. Выйти из просмотра логов можно по **Ctrl+C**, бот при этом продолжит работать.
Напишите боту `/start` в Telegram.

Бот сам перезапустится, если упадёт или если перезагрузить сервер.

## Шаг 8. Включите ежедневную резервную копию

```
crontab -e
```

Если спросит, какой редактор выбрать, нажмите `1` (nano). Добавьте в конец файла строку:

```
0 4 * * * /root/tg_bot_claude/scripts/backup.sh >> /root/backup.log 2>&1
```

Сохраните (Ctrl+O, Enter, Ctrl+X). Теперь каждую ночь в 4:00 по времени сервера база копируется в `data/backups`, копии хранятся 14 дней.

Сделать копию вручную: `./scripts/backup.sh`

## Как обновить бота

Когда в репозитории появляются новые изменения (например, после очередного pull request):

```
ssh root@123.45.67.89
cd tg_bot_claude
./scripts/update.sh
```

## Полезные команды

| Что сделать | Команда (в папке `tg_bot_claude`) |
|---|---|
| Посмотреть логи | `docker compose logs -f` (выход: Ctrl+C) |
| Узнать, работает ли бот | `docker compose ps` |
| Перезапустить | `docker compose restart` |
| Остановить | `docker compose down` |
| Запустить снова | `docker compose up -d` |
| Обновить до новой версии | `./scripts/update.sh` |
| Резервная копия сейчас | `./scripts/backup.sh` |
| Выйти с сервера | `exit` |

## Если что-то не так

| Проблема | Что делать |
|---|---|
| `TelegramConflictError` в логах | Бот запущен где-то ещё (например, на компьютере). Остановите второй экземпляр |
| `Unauthorized` в логах | Неверный токен в `.env`. Выполните `nano .env`, исправьте токен, затем `docker compose up -d` |
| `BOT_TOKEN не задан` | Нет файла `.env`. Повторите шаг 5 |
| Долго нет `Start polling`, ошибки соединения | Серверу недоступен Telegram. Выберите сервер в другой стране |
| `ssh: connect ... timed out` | Проверьте IP-адрес и что сервер включён в панели провайдера |
