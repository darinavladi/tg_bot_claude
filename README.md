# Telegram-бот-планировщик

Бот, которому вы пишете событие с датой и временем, а он сохраняет его и напоминает.

Сейчас умеет:
- добавлять событие по шагам (`/add`): что за событие → когда → повторять ли → категория;
- понимать событие одной фразой: `15.10 18:30 Встреча с Аней`, `завтра в 9 стоматолог`, `через 2 часа позвонить маме`, и затем спрашивать только недостающее (повтор, категорию);
- промежутки времени: `завтра 14:20–19:30 работа над проектом`, `с 14 до 19`;
- повторы с любым периодом: каждый день, по будням, каждую неделю, раз в 2 недели, каждый месяц или свой: `раз в 3 дня`, `каждые 2 недели`, `раз в 3 месяца`;
- свои категории: создаются при добавлении события («➕ Новая категория») или в `/categories`; для начала есть шесть готовых (💼 работа, 🏠 дом…), их можно удалить. Событие можно оставить без категории. Хэштег в тексте (`уборка #дом`) сразу выбирает категорию;
- показывать расписание: `/today` (сегодня), `/week` (7 дней, повторяющиеся события на каждом своём дне), `/list` (всё, по 10 на страницу), с фильтром по категории;
- менять название, время, повтор, категорию и напоминание события или удалять его — кнопкой из списка;
- `/done`: отметить событие завершённым (показывает события на сегодня и пропущенные). Повторяющееся событие после этого переходит к следующему разу;
- `/settings`: часовой пояс, утренняя сводка со списком дел на день, напоминание по умолчанию;
- присылать напоминание (по умолчанию за 15 минут, меняется в `/settings`) с кнопками «💤 Отложить на 10 мин / 1 час».

Данные хранятся в SQLite (файл `planner.db` создаётся сам). Напоминания восстанавливаются из базы при каждом запуске, поэтому не теряются после перезапуска; пропущенные, пока бот был выключен, приходят сразу после запуска.

## Запуск локально

1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и получите токен.
2. Установите Python 3.11+ и зависимости:
   ```bash
   python -m venv .venv
   source .venv/bin/activate        # Windows: .venv\Scripts\activate
   pip install -r requirements-dev.txt
   ```
3. Скопируйте `.env.example` в `.env` и впишите токен в `BOT_TOKEN`.
4. Запустите:
   ```bash
   python -m bot
   ```
5. Напишите боту `/start` в Telegram.
