# Telegram-бот-планировщик

Бот, которому вы пишете событие с датой и временем, а он сохраняет его и напоминает.

Сейчас умеет:
- запоминать события, написанные обычным текстом: `15.10 18:30 Встреча с Аней`, `завтра в 9 стоматолог`, `в пятницу в 7 вечера кино`, `через 2 часа позвонить маме`;
- добавлять событие по шагам: `/add`;
- показывать расписание: `/today` (сегодня), `/week` (7 дней), `/list` (всё, по 10 на страницу);
- менять название, время и напоминание события или удалять его — кнопкой из списка;
- `/settings`: часовой пояс, утренняя сводка со списком дел на день, напоминание по умолчанию;
- присылать напоминание (по умолчанию за 15 минут, меняется в `/settings`) с кнопками «✅ Готово» и «💤 Отложить на 10 мин / 1 час».

Данные хранятся в SQLite (файл `planner.db` создаётся сам). Напоминания восстанавливаются из базы при каждом запуске, поэтому не теряются после перезапуска; пропущенные, пока бот был выключен, приходят сразу после запуска. Следующий этап: повторяющиеся события.

## Запуск локально

1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и получите токен.
2. Установите Python 3.11+ и зависимости:
   ```bash
   python -m venv .venv
   source .venv/bin/activate        # Windows: .venv\Scripts\activate
   pip install -r requirements-dev.txt
   ```
3. Скопируйте `.env.example` в `.env` и впишите токен в `BOT_TOKEN`.
4. Запустите:
   ```bash
   python -m bot
   ```
5. Напишите боту `/start` в Telegram.
